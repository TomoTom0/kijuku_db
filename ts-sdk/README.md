# TypeScript SDK

kijuku-dbのTypeScript SDK実装

## 外部プロジェクトから使用する場合

**[TypeScript SDK利用ガイド](../docs/usage/sdk/ts/README.md)**を参照してください。

- インストール方法（bun link、ローカルパス、Git URL）
- 基本的な使い方（CRUD、検索、タグ、トランザクション）
- 高度な機能（バックアップ、リモートDB操作）
- TypeScript型定義の活用
- エラーハンドリング
- トラブルシューティング

CLIコマンドからもガイドを参照できます：
```bash
# SDK選択ガイド（デフォルト）
kijuku-cli docs

# TypeScript SDKガイド
kijuku-cli docs ts

# Rust SDKガイド
kijuku-cli docs rust

# API仕様書
kijuku-cli docs api
```

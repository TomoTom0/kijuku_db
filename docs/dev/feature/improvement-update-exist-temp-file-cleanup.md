# update_exist 一時ファイルの自動削除仕組み

## 現状
`update_exist` 機能は処理結果を一時ファイル（`-detail.json`, `-ids.json`）に書き出している。
ドキュメントでは呼び出し側の責任で削除すると明記されているが、大量実行時にディスク容量を圧迫するリスクがある。

## 問題点
- 一時ファイルに自動削除仕組みがない
- 呼び出し側が削除を忘れた場合、一時ファイルが残留し続ける
- 大量実行シナリオでディスク容量が枯渇する可能性

## 改善案
1. `Drop` トレイトを実装したラッパー構造体で一時ファイルを管理し、スコープ終了時に自動削除
2. 処理終了時にクリーンアップする仕組みを追加
3. 一時ファイルの TTL（有効期限）を設定し、期限切れファイルを自動削除

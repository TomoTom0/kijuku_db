# v0.3.4 (2026-11-21)

## Added

### Web GUI サーバー層のテスト導入 (#67 / TASK-101)

- Rust `rust-sdk/tests/server_test.rs`（7件）と TS `ts-sdk/test/integration/server.test.ts`（7件）を追加。未認証401（media 3 endpoint）・誤パスワード401・login 成功（`Set-Cookie` の `session_id`/`session` → 保護 endpoint へのアクセス可）・limit/offset の `count`/`total` 分離・title フィルタ・order 指定の並び順・detail の tags/attributes 付随・存在しない id/uuid で404・logout 後の同一セッション401をカバー
- テスト可能化のためのリファクタリング: Rust は `ServerState::new` / `build_app` を抽出、TS は Hono アプリ構築を `createApp` として `startServer` から分離し export（`startServer` はパスワード生成・バナー表示・listen 専用）。振る舞いは不変

### D1 大規模リストの実環境テスト (#67 / TASK-103)

- `rust-sdk/tests/d1_test.rs` に1200件の `uuid_in` / `id_in` テストを追加。`json_each` によるIN句の1パラメータ化（v0.3.3 #62）が、D1 のバインド上限（100）を超えるリストで実際に動作することを検証

### bulk_load_test の検証強化 (#66)

- verify の「内容不一致」系エラーパス（title 改変・attributes 不一致・hashes 不一致）を検出するテストを追加
- 件数不一致の assert を `contains("media 件数不一致")` に強化
- 属性（key/value/value_type）とハッシュ（content_hash）をテスト内で明示 assert
- alternative_of（代替ハッシュ連鎖）付きハッシュの転送が正しく運ばれることを検証

## Fixed

- deploy スクリプト (`scripts/dev/deploy-local.sh`) がプロジェクト直下の `target/` を前提としていたのを修正 (#65)。`target-dir` は `.cargo/config.toml` のマシンローカル設定（git管理外）のため、ビルド後に `cargo metadata` でビルド出力ディレクトリを解決するようにした
- Web GUI サーバー (Rust) の axum 0.8 互換の実バグ2件を修正 (#67 / TASK-101)。①ルート構文を `:id` / `*path` から `{id}` / `{*path}` に変更（旧構文は Router 構築時に panic）②auth middleware を `from_fn` + Extensions 経由の state 取得から `from_fn_with_state` + `State` 抽出に変更（axum 0.8 では `Router::layer` 配下の middleware 実行時点で Extensions に state が入らず常に500になる）
